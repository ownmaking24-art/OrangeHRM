# OrangeHRM Automation Framework

Automation Testing Framework for the OrangeHRM application using Selenium, Java, TestNG, and Maven.

---

## 📌 Project Overview

This project is designed to automate the testing of the OrangeHRM web application.  
The framework follows industry-standard automation practices such as:

- Page Object Model (POM)
- TestNG Framework
- Maven Build Management
- Reusable Utilities
- Data-driven testing approach
- Reporting and Logging

The framework helps in validating core HR functionalities like login, employee management, dashboard verification, and more.

---

## 🛠 Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Git & GitHub
